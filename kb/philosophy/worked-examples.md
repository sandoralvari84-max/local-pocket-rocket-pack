# Philosophy — worked examples (mentor-curated, round 3: reasoning by example)

Method: restate → retrieve facts → reason in steps → check → concise answer.

## Example 1 — "Is this a good argument? 'All men are mortal; Socrates is a man; therefore Socrates is mortal.'"
- Restate: assess the classic syllogism for validity and soundness.
- Facts (advanced.md › Logic): validity = conclusion follows if premises are true; soundness = valid + true premises.
- Steps:
  1. Validity: if both premises are true, the conclusion must be true. The form (all A are B; x is A; so x is B) is valid.
  2. Soundness: are the premises actually true? "All men are mortal" and "Socrates is a man" are both true.
  3. Valid + true premises ⇒ sound.
- Check: separates validity (form) from soundness (truth of premises); both satisfied.
- Answer: Yes — it's both valid (the conclusion follows from the form) and sound (the premises are true), so the conclusion is guaranteed.

## Example 2 — "Trolley problem: a runaway trolley will kill five; pulling a lever diverts it to kill one. Pull it?"
- Restate: analyse the dilemma using the main ethical frameworks rather than assert one answer.
- Facts (foundations › ethical theories; advanced.md › Ethics): consequentialism, deontology, virtue ethics.
- Steps:
  1. Consequentialist/utilitarian view: compare outcomes — one death < five, so pull the lever to minimise total harm.
  2. Deontological view: focus on duties/rights — actively diverting to kill one uses that person as a means; some hold it's wrong to actively cause a death even for a better outcome.
  3. Virtue view: what would a person of good character do? It asks about intent and character, not a formula.
  4. Note the contrast case ("fat man" variant) where most people's intuition flips, showing acts vs consequences differ.
- Check: presents multiple frameworks fairly without forcing a single verdict; matches the KB's neutral stance.
- Answer: There's no single correct answer. Utilitarian reasoning favours pulling the lever (five lives over one); deontological reasoning may forbid actively causing a death as a means; virtue ethics asks about character and intent. A good answer lays out the trade-off, not a verdict.
